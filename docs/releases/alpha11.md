# v0.1.0-alpha.11

入力中の負荷を減らし、確定をまたいだ学習を直した版です。

### 改善

- 1打鍵ごとに行っていた設定ファイルの読み込みとJSON解析をやめ、更新されたときだけ読み直すようにしました。1回あたり150µsから0.4µsになります。
- 直前の文章（文脈）の読み取りを、入力開始・変換・部分確定のときだけにしました。ブラウザやWordのように文書の読み取りが重いアプリで、打鍵ごとの待ちが減ります。
- 候補ウィンドウへの不要な更新を省きました。候補が空のまま変わらないときは描き直さず、テーマも変更されたときだけ反映します。
- 学習データの保存を、確定ごとから「確定して3秒操作がないとき」のまとめ書きにしました。確定の処理時間は中央値16.2msから0.37msになります。学習は保存前から変換に反映されます。

### 修正

- 確定のたびに直前の語が忘れられ、確定をまたいだ語のつながりが学習されていませんでした。前回確定した文字列の直後に続けて入力した場合は、そのつながりを学習します。

### 注意

- 設定画面での変更が入力に反映されるまで、最大0.5秒かかります。
- 確定から3秒以内にエンジンが強制終了すると、その直前の学習が保存されないことがあります。

### インストール

`azookey-setup.exe`を実行してください。更新後は作業を保存してWindowsからサインアウトし、再度サインインしてください。`azookey-setup.exe.sha256`でセットアップEXEのSHA256を確認できます。

### 検証範囲

Windows CIのビルドと、Rust・Swift・フロントエンドのテスト、x64/x86と配布ファイルの照合を通過したものだけを配布します。開発環境（RTX 4070 Ti、CUDA、推論2回）で、配布物のエンジンを使った44例の回帰セットは先頭一致44/44件でした。変換の中央値は28.65ms、240キーの入力応答の中央値は0.69msです。打鍵ごとに省いたTSF・候補ウィンドウの処理は、この計測に含みません。更新インストール後のネイティブアプリでの実入力は確認中です。安定版ではありません。
