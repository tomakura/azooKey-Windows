English word data
=================

english-words.txt contains 39,095 lowercase ASCII words from SCOWL
(Spell Checker Oriented Word Lists), release 2020.12.07, English/American
sizes 10, 20 and 35. Words of fewer than two letters are excluded.

Source release: https://github.com/en-wl/wordlist/tree/rel-2020.12.07
The supplied subset was obtained from Meltype dictionaries/english-words.txt
at revision 8ffbf4bc89a368501a24cb25d6dd11891bec56aa:
https://github.com/yksr-melt/Meltype/blob/8ffbf4bc89a368501a24cb25d6dd11891bec56aa/dictionaries/english-words.txt
Its header was replaced with SCOWL attribution; the word lines are unchanged. Meltype explicitly
identifies this data as SCOWL and reproduces its permissive license in
THIRD-PARTY-NOTICES.md. SCOWL-LICENSE.txt contains the original release's
full copyright and license notices. Those notices also apply to this subset.

No Meltype program code, GPL dictionaries, or dictionary-generation scripts
are included. MixedInput.swift is an independent implementation of English
span recognition using azooKey's input-style API.
